# Product Overview

## Observability Demo POC

A proof-of-concept demonstrating modern observability patterns in .NET applications using .NET Aspire.

## Purpose

This project showcases:
- **Distributed Tracing**: Track requests across service boundaries
- **Metrics Collection**: Monitor application performance and behavior
- **Health Checks**: Ensure service availability and readiness
- **Service Discovery**: Enable dynamic service-to-service communication
- **Resilience Patterns**: Built-in retry, circuit breaker, and timeout policies

## Core Components

- **Order Service API**: RESTful API demonstrating observable endpoints
- **App Host**: .NET Aspire orchestrator for local development and deployment
- **Service Defaults**: Shared observability configuration and extensions

## Domain

E-commerce order management system with endpoints for:
- Orders
- Customers
- Catalog
- Demo/testing APIs
